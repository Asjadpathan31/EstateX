## 🏠 About EstateX

**EstateX** is a full-stack real estate web application that allows users to browse, list, and manage property listings. Built with a modern MERN-style stack, it provides a clean and responsive UI for buyers and sellers to connect seamlessly.

> 🔑 Find your dream property — fast, simple, and modern.

---

## ✨ Features

- 🏡 Browse property listings with filters
- 📋 Add & manage property listings
- 🔍 Search by location, price, and type
- 📱 Fully responsive design
- 🔐 User authentication & authorization
- 🗂️ Clean dashboard for managing listings

## 🚀 Getting Started

### Prerequisites
```bash
node >= 14.x
npm >= 6.x
MongoDB running locally or Atlas URI
```

### Installation

```bash
# Clone the repository
git clone https://github.com/Asjadpathan31/EstateX.git

# Go into the project
cd EstateX

# Install frontend dependencies
cd frontend
npm install

# Install backend dependencies
cd ../backend
npm install

# Install Python dependencies (if any)
pip install -r requirements.txt
```

### Run the App

```bash
# Start backend
cd backend
npm start

# Start frontend (new terminal)
cd frontend
npm start
```

App will run on `http://localhost:3000`
